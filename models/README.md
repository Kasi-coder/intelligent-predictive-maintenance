# Model Artifacts

The production model is a Random Forest pipeline trained on the reproducible AI4I-schema fallback dataset.

The full binary artifact `predictive_maintenance_model.pkl` is included in the complete project ZIP distributed with this project. The connected GitHub integration used for this repository does not support committing the 6+ MB binary artifact reliably, so the repository keeps the model metadata and evaluation results in version control.

To run the API locally, use the complete project ZIP so the `models/predictive_maintenance_model.pkl` file is present.
